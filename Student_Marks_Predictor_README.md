# 📚📊 Student Marks Prediction using Machine Learning

This project implements a **machine learning-based regression system** to predict **student marks 🎓** based on their **study hours ⏱️**. The model is trained on structured data and can accurately estimate performance on unseen inputs.

## 📌 Project Overview
The goal of this project is to build a **regression model** that predicts **student marks 📈** using features like **study hours**. Machine learning algorithms are used to understand the relationship between study time and academic performance.

## 📂 Dataset
- Dataset: Student Study Hours Dataset  
- Data Type: Structured (CSV)  
- Features: Study Hours ⏱️  
- Target: Student Marks 📊  

## ⚙️ Features
- Data preprocessing and cleaning  
- Data visualization (scatter plots)  
- Train-test split  
- Multiple model comparison  
- Regression analysis  
- Model evaluation using performance metrics  

## 🧠 Model & Training
- Models Used:  
  - Linear Regression  
  - Support Vector Regression (SVR)  
  - K-Nearest Neighbors (KNN)  
  - Decision Tree Regressor  
  - Random Forest Regressor  
  - XGBoost Regressor  

- Train-Test Split: 80% / 20%  
- Evaluation Metrics:  
  - Mean Squared Error (MSE)  
  - Root Mean Squared Error (RMSE)  
  - R² Score  

## 📊 Results
The models performed well on test data. **KNN Regressor** was used for final predictions. Ensemble models like **Random Forest** and **XGBoost** also showed strong performance in predicting student marks.

## 🛠️ Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Scikit-learn  
- XGBoost  
- Joblib

## 📌 Conclusion
This project demonstrates how machine learning can be used to **predict student performance 📚**. The model can be further improved by using more features and tuning hyperparameters.
