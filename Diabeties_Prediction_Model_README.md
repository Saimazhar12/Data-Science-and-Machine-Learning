# 🩺🧪 Diabetes Prediction using Machine Learning

This project implements a **machine learning-based prediction system** to determine whether a person is likely to have **diabetes** based on medical attributes. The model is trained on structured healthcare data and can accurately predict unseen cases.

## 📌 Project Overview
The goal of this project is to build a **binary classifier** that identifies whether a patient is **diabetic 🩺** or **non-diabetic ✅**. Machine learning algorithms learn patterns from features like glucose level, BMI, and age.

## 📂 Dataset
- Dataset: Diabetes Dataset  
- Data Type: Structured (CSV)  
- Features: Glucose, BMI, Age, Blood Pressure, etc.  
- Classes:  
  - Diabetic 🩺  
  - Non-Diabetic ✅  

## ⚙️ Features
- Data preprocessing and cleaning  
- Handling missing values  
- Feature scaling (StandardScaler)  
- Data visualization (heatmap, plots)  
- Multiple model comparison  
- Binary classification  
- Confusion matrix evaluation  

## 🧠 Model & Training
- Models Used:  
  - Random Forest Classifier  
  - K-Nearest Neighbors (KNN)  
  - XGBoost Classifier  
- Train-Test Split: 80% / 20%  
- Evaluation Metric: Accuracy  
- Feature Scaling: StandardScaler  

## 📊 Results
The models achieved strong performance on test data. Ensemble methods like **Random Forest** and **XGBoost** performed best in predicting diabetes cases.
